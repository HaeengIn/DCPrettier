# DCPrettier

디시인사이드의 불필요한 요소들을 삭제해주는 확장 프로그램

## 설치

- 프로젝트 다운로드 받기

    1. [Release 페이지](https://github.com/HaeengIn/DCPrettier/releases/latest)에서 `Source code (zip)`을 클릭해 프로젝트를 다운로드 받습니다.

    2. 다운로드 받은 압축 파일을 해제합니다.

    3. 브라우저 설정 --> 확장 프로그램으로 이동합니다.

    4. 우측 상단에 `개발자 모드`를 활성화합니다.

    5. 좌측 상단에 `압축해제된 확장 프로그램 로드`를 클릭합니다.

    6. `DCPrettier-<버전>` 폴더 안에 있는 `DCPrettier`를 클릭하고 `열기`를 누릅니다.

- Chrome 웹 스토어에서 다운로드 받기

  - 추후 지원 예정

## 기여

아래 명령어를 통해 리포지토리를 복사하고 프로그래밍 한 후, 풀 리퀘스트를 열어주세요.

```bash
git clone https://github.com/HaeengIn/DCPrettier.git
```
